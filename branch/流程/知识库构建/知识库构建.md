# 知识库构建

把本次任务所需的外部知识沉淀进 `references/`，拓扑至不可再出新领域为止。

## 动作

1. 选题：编程侧（代码质量、算法、模式、重构、领域建模）+ 项目侧（排期、人因、敏捷）。
2. 抓取：`python -B scripts/knowledge_fetch.py --url <白名单页> --out tmp/downloads`
   （白名单：book.douban.com / zh.cppreference.com / cppreference.cn / cmake.com.cn /
   isocpp.org / github.io 镜像；须 `:grant network`。本环境境外直取常 WinError 10060，
   ≥4 词英文书名会被切成词典页 -> 改中文书名或 `site:book.douban.com <词>`）。
3. 转换：`knowledge_convert.py` 把 HTML 转 md 摘要，**只存摘要与出处，不存版权正文**。
4. 落库：`references/<领域>/<主题>.md`，每文件 ≤50 行，含来源与版权标注。
5. 拓扑判据：新主题能引出未覆盖的相邻领域 → 继续；引不出 → 收口。
5b. 未确证条目一律标 `[本地]` 且**不附 URL**（红线：严禁臆造 URL），见
   [`references/references.md`](../../../references/references.md) 的来源标注约定。

## 产出

- [`references/references.md`](../../../references/references.md) 索引 + 各领域子目录。

## 兜底

- 网络不可用：降级为本地既有资料 + 向用户说明缺口，禁止编造文献内容。
- 缓存文件禁止写入 skill 目录（一律落用户缓存目录 / tmp）。
