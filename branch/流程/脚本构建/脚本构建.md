# 脚本构建

按大纲与分支裁决写代码；本体薄，规范与范式经依赖获取。

## 动作

1. 脚手架：`python -B scripts/scaffold_project.py --target tmp/<proj> --layout src,tests`。
2. 编码：调用 [code-guidelines](../../../dependence/dependence.md) 取命名/注释/复杂度准则，
   调用 [pavedpath-code](../../../dependence/dependence.md) 取已验证实现范式。
3. 单文件 ≤50 行：超限即拆「入口脚本 + 模块」，禁止长文件。
4. 每模块随写随测：先写最小可运行片段，再补边界与错误路径。
5. 静态自查：`python -B scripts/lint_check.py --path tmp/<proj>`，问题清零才进构建测试。
6. 每步提交功能分支 `feature/<topic>`（见 git 工作流约束）。

## 禁止

- 臆造 API/参数：任何不确定签名须经 [浏览器学习](../浏览器学习/浏览器学习.md) 取证。
- 复制依赖技能正文进本工程；只引用其能力。
- 静默写盘：默认 `--dry-run`，落盘须显式 `--yes`。
