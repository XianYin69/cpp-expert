# 流程（Process）

本目录存放 cpp-expert 的执行流程细则，每步独立成文件夹（文件夹名=流程名）。

## 两条独立路径

创建与修改是两条完全独立的流程，各自从「初始化」开始，互不交织。

### 创建流程

```
[初始化/](初始化/初始化.md) → [需求确认/](需求确认/需求确认.md) → [经验查询/](经验查询/经验查询.md) →
[大纲构建/](大纲构建/大纲构建.md) → [分支分析/](分支分析/分支分析.md) → [脚本构建/](脚本构建/脚本构建.md) →
[构建测试/](构建测试/构建测试.md) → [知识库构建/](知识库构建/知识库构建.md) →
[浏览器学习/](浏览器学习/浏览器学习.md) → [约束编写/](约束编写/约束编写.md) →
[整体审查/](整体审查/整体审查.md) → [收尾/](收尾/收尾.md) → 完成
```

### 修改流程

```
[初始化/](初始化/初始化.md) → [修改流程/](修改流程/修改流程.md) → 完成
```

## 步骤列表

| 步骤 | 路径 | 说明 |
|---|---|---|
| 初始化 | [`初始化/`](初始化/初始化.md) | 建工作空间、MIT、git init（两条路径共同前置） |
| 需求确认 | [`需求确认/`](需求确认/需求确认.md) | 澄清任务：输入/输出/语言/运行环境/验收标准 |
| 经验查询 | [`经验查询/`](经验查询/经验查询.md) | 检索链与本地知识库既往经验 |
| 大纲构建 | [`大纲构建/`](大纲构建/大纲构建.md) | 模块与接口大纲，交用户审阅 |
| 分支分析 | [`分支分析/`](分支分析/分支分析.md) | 语言/库/算法分支与约束取舍 |
| 脚本构建 | [`脚本构建/`](脚本构建/脚本构建.md) | 写代码（经 code-guidelines/pavedpath-code） |
| 构建测试 | [`构建测试/`](构建测试/构建测试.md) | 编译/运行/单测，失败即回脚本构建 |
| 知识库构建 | [`知识库构建/`](知识库构建/知识库构建.md) | 编程书与项目书文献入 references/ |
| 浏览器学习 | [`浏览器学习/`](浏览器学习/浏览器学习.md) | 不明处派 file_ops 联网学习并沉淀 |
| 约束编写 | [`约束编写/`](约束编写/约束编写.md) | 编写与合并约束规则 |
| 整体审查 | [`整体审查/`](整体审查/整体审查.md) | 九项标准整体审查 |
| 收尾 | [`收尾/`](收尾/收尾.md) | 交付、提示词、git、垃圾回收 |
| 修改流程 | [`修改流程/`](修改流程/修改流程.md) | 修改已有代码/技能（独立路径） |

## 全局机制

各步骤根 md 接入 `resistance/` 五大机制（垃圾回收、上下文压缩、逻辑链、过程链存取、惩罚）
与 `scripts/` 对应脚本；依赖能力见 [`dependence/`](../../dependence/dependence.md)。
