- 原作名：The C++ Programming Language, 4th Edition
- 作者：Bjarne Stroustrup（C++ 设计者与最初实现者）；译 王刚、杨巨峰
- 出版：机械工业出版社，2016-7
- 出处：https://book.douban.com/subject/26857943/ （[联网] 取证 2026-09-28）
- 映射知识叶：headers-modules · templates-concepts · concurrency-memory-model · ub-portability

## 摘要（要点为 [本地] 常识，书目信息为 [联网] 确证）

1. 语言设计者亲撰的参考级著作，覆盖 C++11 完整特性与标准库的设计动机。
2. 用于「为什么这样规定」层面：语义定义、内存模型与并发设施、模板与重载决议原理。
3. 语法细节与函数签名请查 cppreference，本书不充当速查手册。
4. 局限：非入门书；不含构建工具链与静态分析器实操。
